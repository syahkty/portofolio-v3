Halo semuanya! 👋

## 🛠️ Tech Stack

Proyek ini dibangun menggunakan teknologi web modern:

- **ReactJS** - Frontend framework
- **Tailwind CSS** - Utility-first CSS framework
- **Supabase** - Backend untuk data portofolio, sertifikat, dan sistem komentar
- **AOS** - Animate On Scroll library
- **Framer Motion** - Animation library
- **Lucide** - Icon library
- **SweetAlert2** - Beautiful alert dialogs

## Cara Menjalankan Secara Lokal (Getting Started)

### Persyaratan

- Node.js `>= 14.x`
- npm atau yarn

### 1. Install Dependencies

Buka terminal dan jalankan:

    npm install

> Jika ada kendala *peer dependency*: `npm install --legacy-peer-deps`

### 2. Environment Variables

Buat file bernama `.env` di folder utama (root):

    VITE_SUPABASE_URL=your-supabase-project-url
    VITE_SUPABASE_ANON_KEY=your-supabase-anon-key

> Dapatkan *key* ini di proyek Supabase pada menu **Settings → API**.  
> ⚠️ Jangan pernah mengunggah file `.env` ke GitHub — pastikan file ini ada di dalam `.gitignore`.

### 3. Setup Database Supabase

Masuk ke proyek Supabase kamu → **SQL Editor** → jalankan *script* di bawah ini (cukup sekali):

    -- TABLES
    CREATE TABLE public.projects (
      id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
      title text,
      description text,
      img text,
      link text,
      github text,
      features jsonb,
      tech_stack jsonb,
      is_published boolean DEFAULT true,
      order_index int DEFAULT 0,
      created_at timestamptz DEFAULT now()
    );

    CREATE TABLE public.certificates (
      id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
      img text,
      created_at timestamptz DEFAULT now()
    );

    CREATE TABLE public.portfolio_comments (
      id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
      content text NOT NULL,
      user_name text NOT NULL,
      profile_image text,
      is_pinned boolean DEFAULT false,
      created_at timestamptz DEFAULT now()
    );

    CREATE TABLE public.profiles (
      id uuid PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
      username text UNIQUE NOT NULL,
      role text NOT NULL CHECK (role IN ('admin', 'user')),
      created_at timestamptz DEFAULT now()
    );

### 4. Enable Realtime (Untuk Komentar)

Pergi ke **Table Editor → portfolio_comments → Enable Realtime**.

### 5. Membuat Akun Admin

**Langkah 1** — Masuk ke **Authentication → Users → Add User** di Dashboard Supabase, lalu salin User ID yang dihasilkan.

**Langkah 2** — Jalankan perintah ini di SQL Editor (ganti `USER_UUID` dengan ID yang baru disalin):

    INSERT INTO public.profiles (id, username, role)
    VALUES ('USER_UUID', 'andis', 'admin');

### 6. Jalankan Server Lokal

    npm run dev

Buka `http://localhost:5173` di browser kamu.
